SecretLetter

A stateless zero-storage cryptography platform with a decoupled headless PHP API and interactive client.

PHP 8+ OpenSSL Decoupled API MVC Controllers Zero-Storage JavaScript Client
Launch Live Platform ↗ View GitHub Repository ↗

1. Overview

SecretLetter is an end-to-end confidential transmission platform built around one foundational engineering requirement: absolute zero-storage cryptography.

Instead of storing encrypted messages in a database (where metadata, IPs, or cipher texts can be subpoenaed or breached), SecretLetter treats the backend as a stateless calculation engine. Plaintext enters, cipher transformations are applied in memory via OpenSSL, and the resulting payload is returned directly to the client before memory is reclaimed.

2. The Problem

Most "secure messaging" services store encrypted data in central databases. Even with end-to-end encryption, the existence of stored records provides attackers with data to attempt offline brute-force attacks or reconstruct communication metadata.

Users sending sensitive snippets (passwords, credentials, private notes) needed an ephemeral tool with zero persistent digital footprint and parameterized cryptographic iterations.

4. Key Engineering Decisions

Decoupled Frontend & Headless API

Separating the UI onto Vercel Edge while keeping the PHP API as a dedicated service allows the frontend to load instantaneously across CDNs while keeping the backend focused purely on cryptographic calculations.

Native OpenSSL Primitives over Bulky Libraries

Avoided heavy third-party vendor dependencies by leveraging PHP's native OpenSSL module directly. This minimizes attack surface and enforces standard initialization vector (IV) prepending.

Stateless Zero-Storage Model

No MySQL or disk logging is attached to the cipher service. Payloads are processed strictly in volatile memory and wiped upon HTTP response termination.

5. Challenges & Reflections

Real Challenge: Multi-Round IV Byte Slicing

When users specify multiple encryption iterations (1 to 5 passes), maintaining correct base64 encodings and matching initialization vector lengths on successive decryption passes required careful byte-boundary extraction in Decrypter.php.

What I learned: Building SecretLetter gave me concrete experience with cryptographic engineering, headless REST API contracts, and the architectural benefits of decoupling compute services from persistent storage.
