Elyra Mental Wellness

A mental wellness platform built with structured MVC architecture, custom authentication middleware, and database-driven dashboards.

PHP MVC MySQL Relational Auth Middleware Role-Based RBAC Session Security JavaScript
Launch Live Demo ↗ View GitHub Repository ↗

1. Overview

Elyra was built as our BCA final-year capstone project. As the backend engineering lead on the project, I was responsible for the architectural foundation: directory modularity, relational MySQL database schema design, session management, user authentication guards, and data interaction controllers.

2. The Problem

A mental wellness companion requires secure handling of personal reflections, mood assessments, and account sessions. It also requires clear privilege boundaries between standard users and system administrators.

Rather than relying on heavy monolithic CMS platforms, we needed a lightweight, transparent codebase with clear separation between data queries (Models), request validation (Controllers), and interface rendering (Views).

4. Key Engineering Decisions

Custom Authentication Middleware (`auth.php`)

Implemented dedicated middleware functions (e.g. guest_middleware()) that guard authenticated view routes, cleanly redirecting unauthenticated visitors while preserving return destinations.

Structured MVC Directory Layout

Organized the application into strictly delineated Controller/, Model/, View/, and necessary/ modules, making team collaboration straightforward and preventing spaghetti code.

5. Challenges & What I Learned

Real Challenge: Session Synchronization Across Dynamic Views

Ensuring session state and user preferences (such as dynamic mood themes) persisted smoothly without layout flickering across shared hosting server configurations.

What I learned: Leading backend development for a team capstone project reinforced the importance of clear architectural contracts, database normalization, and defensive input validation.
