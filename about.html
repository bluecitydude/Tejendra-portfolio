How I Approach Software Development

In an era where many developers rely solely on templates and high-level libraries without inspecting what runs underneath, I focus on understanding the engine: how HTTP request lifecycles work, how session cookies are guarded against tampering, how database indexing influences latency, and how cryptographic primitives like OpenSSL ensure data confidentiality.

I believe practical projects are the true metric of engineering capability. In my capstone project, Elyra, I took ownership of the backend: structuring MVC controller logic, writing custom authentication middleware, and designing relational MySQL schemas. In SecretLetter, I built a headless PHP API with zero-storage architecture to guarantee user privacy.
